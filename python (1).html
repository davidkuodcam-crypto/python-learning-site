1.1 語言世代、運算思維演算法與 Spyder IDE 實戰介面

★ 程式語言分類與 Python 特性
  • 語言階層：機器語言（最低階）➔ 組合語言（與硬體密切相關，非高階語言）➔ 高階語言（如 Python、C、Java，符合人類語意）。
  • 直譯式語言：Python 屬於直譯式（Interpreted）語言，跨平台、簡潔易讀、擴充性強（廣泛用於 AI、大數據、自動控制、遊戲設計）。
  • 易錯陷阱：Python 沒有指標（Pointer）概念（C/C++ 才有指標）。
★ 運算思維與演算法 (Algorithm)
  • 運算思維 4 步驟：拆解 (Decomposition) ➔ 模式識別 (Pattern Recognition) ➔ 歸納抽象化 (Abstraction) ➔ 演算法 (Algorithm，最終目標與核心關鍵)。
  • 演算法五大特性：輸入（0 或多個輸入）、輸出（至少 1 個輸出）、明確性（步驟清楚無歧義）、有效性（具體可行）、有限性（絕不允許無窮迴路！）。
★ Python 註解與區塊縮排規範
  • 單行註解：放在任何一行的井字號 # 之後（注意：Python 不支援 // 或 /* */）。
  • 多行字串/註解：使用成對的三重單引號 '''...''' 或三重雙引號 """..."""，可固定多行輸出格式。
  • 程式碼層級區分：透過縮排（Indentation，1 個 Tab 或 4 個空白）區分區塊，若太長可用反斜線 \ 換行續寫。

深入理解 Python 「動態型別、強型別」機制與變數命名規則，徹底分辨一般除法 /、整數除法 //、取餘數 % 與次方開根號 ** 0.5 的輸出型態差異，並掌握複合指派與位元位移運算。

2.1 變數命名規則、動態強型別與算術運算結果型態對照表

★ Python 變數命名與指派四大鐵則
  • 不必事先宣告型態：使用等號 = 將右方資料指派給左方變數時即自動決定型態（但使用複合指派如 x += 1 前，變數 x 必須已事先設定初值！）。
  • 合法命名規則：可包含英文字母、數字、底線 _，且支援中文變數名稱；第一個字元絕不能是數字，中間不可有空白，亦不可使用保留字（如 if, for, def）。
  • 區分大小寫：Score 與 score 視為兩個完全不同的變數。
★ 為什麼 Python 是「動態型別、強型別」？
  • 動態型別 (Dynamic Typing)：執行期間變數可隨時改變綁定的資料型態，不需事先宣告。
  • 強型別 (Strong Typing)：不容許不合理的隱式型態轉換（例如字串 '1.0' 與數字 2 直接相加會報 TypeError，必須明確轉型）。
  • 算術型態提升：當 int 與 float 混合運算時，結果一律自動提升為範圍較大的 浮點數 (float)！
類別 Python 運算式範例 輸出結果 關鍵考點說明
浮點數加減乘 1.0 + 2.0 ｜ 1.0 + 2 ｜ 5.0 * 2 3.0 ｜ 3.0 ｜ 10.0 只要任一運算元為 float，結果必定帶 .0（不會印出多餘的 3.000000）。

2.2 運算子優先順序視覺化拆解與捷徑邏輯運算

互動逐步拆解引擎

Python 運算優先順序由高至低為：括號 () ➔ 次方 ** ➔ 正負號 +x/-x (一元運算子) ➔ 乘除 * / // % ➔ 加減 + - ➔ 位元位移 << >> ➔ 比較 > < == ➔ not ➔ and ➔ or。
例如認證考題：(3 * (1 + 2) ** 3 - (2 ** 3) * 2) ➔ 先算括號與次方得 3 * 27 - 8 * 2 ➔ 再算乘法得 81 - 16 ➔ 最終結果為 65！
此外，and 與 or 具備快捷運算（Short-circuit evaluation）特性：例如 result = (48 % 6 == 0) and (24 % 4 == 0) 因兩邊餘數皆為 0（皆為 True），故 result 回傳 True。

迴圈結構：range()、for 迴圈與 while 迴圈

Python 專門用來處理重複執行事件的命令稱為「迴圈」。本章完整收錄第 4 章教材的 range() 整數數列產生器、固定次數的 for 迴圈与巢狀迴圈、流程跳躍指令 break / continue，以及不固定次數的 while 條件迴圈，並額外設計 5 個附件沒有的原創實務好範例！

4.1 認識 range() 函式：建立整數循序數列

1. 單一參數：range(終止值)

從 0 開始，每次遞增 1（預設增減值為 1），直到「終止值 - 1」為止（不包含終止值本身！）。
例如：range(5) ➔ 0, 1, 2, 3, 4

2. 雙參數：range(起始值, 終止值)

從「起始值」開始到「終止值 - 1」，預設每次加 1（可為負整數）。
例如：range(2, 8) ➔ [2, 3, 4, 5, 6, 7]
例如：range(-2, 4) ➔ [-2, -1, 0, 1, 2, 3]

3. 三參數：range(起始, 終止, 間隔)

若間隔值為負數（遞減），起始值必須大於終止值，否則會產生空數列！
例如：range(8, 3, -1) ➔ [8, 7, 6, 5, 4]
陷阱：range(2, 5, -2) ➔ 起始 < 終止卻遞減，不顯示任何內容（空數列）！

⚡ range(start, stop, step) 即時視覺化測試器
執行 list(range(1, 10, 2)) 產生的數列結果：
[1, 3, 5, 7, 9] （共 5 個元素）

4.2 for 固定次數迴圈與巢狀迴圈（累加總和、直角三角形、九九乘法表）

for 變數 in 數列: 可依序走訪任何序列項目（如 range() 或串列 ['apple', 'banana']）。當迴圈內又包含另一個迴圈時稱為巢狀迴圈（Nested Loop），注意內外層迴圈結構必須完整包覆，絕對不可交錯！

# 1. 顯示正整數數列 (numshow.py) 與計算 1 到 n 總和 (numtotal.py)
n = int(input("請輸入正整數："))
total = 0
for i in range(1, n + 1):
    print(i, end=" ")
    total += i

# 2. 巢狀 for 迴圈：井字/星號直角三角形 (fornest.py 與認證必考題對照)
# 寫法 A：內層 range(0, x)，第 1~5 行分別印出 1, 2, 3, 4, 5 顆星
for x in range(1, 6):
    for y in range(0, x):
        print("*", end="")

4.3 break / continue 控制命令與 while 條件迴圈

break（強制跳離整個迴圈）

在迴圈執行中途一旦遇到 break，會立刻終止並跳出該層迴圈，繼續執行迴圈後方的程式。常用於「找到第一個符合條件的值（如最小公倍數、最大公因數）即刻停止」。

continue（跳過當次、繼續下一輪）

遇到 continue 時，會略過當次迴圈下方尚未執行的敘述，直接跳回迴圈開頭進行下一輪迭代。例如：if x % 3 == 0: continue 會排除所有 3 的倍數。

while 迴圈三要件與無窮迴圈防範

while (條件式): 用於次數不固定的迴圈，進入迴圈前會先檢查條件式。必須具備：(1) 變數初始值、(2) 條件判斷式、(3) 調整變數增減值。陷阱：若 a = 0; while a < 6: a = a * 2，因 $0 \times 2$ 永遠為 $0$，將陷入無窮迴圈！

ch04_break_continue_while.py（最小公倍數 multiple.py / 排除倍數 except5.py / 階乘 while.py） 
# 1. break 實作：找兩數的最小公倍數 (multiple.py)
a = int(input("請輸入 a 的值："))
b = int(input("請輸入 b 的值："))
maxno = a * b
for i in range(1, maxno + 1):
    if i % a == 0 and i % b == 0:
        break  # 找到第一個公倍數即為最小公倍數，立即跳出迴圈！
print(f"{a} 和 {b} 的最小公倍數 = {i}")

# 2. continue 實作：顯示正整數數列，排除 5 的倍數 (except5.py)
n = int(input("請輸入正整數："))
for i in range(1, n + 1):
    if i % 5 == 0:
        continue  # 若為 5 的倍數則跳過本次列印，直接進入下一輪
    print(i, end=" ")
print()

# 3. while 迴圈實作：計算 N! 階乘與解答課本思考題「100! 結尾有幾個 0？」(while.py)
num = int(input("請輸入正整數 n 的值："))
ans = i = 1
while i <= num:
    ans *= i
    i += 1
print(f"{num}! = {ans}")
