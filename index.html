CHAPTER 01

變數、資料型別與運算子

掌握 Python 的語言特性、變數命名規則、基本資料型別與各種運算符號的優先順序。

1.1 Python 語言特性、縮排與註解

Python 是一種高階、直譯式、物件導向的程式語言，具有動態型別（Dynamically Typed）與強型別（Strongly Typed）兩大核心特性：使用變數前不需事先宣告型別，但不同資料型別之間不會隨意進行隱式轉型（例如 1 + "2" 會產生 TypeError）。

縮排（Indentation）與註解
  • 縮排決定程式區塊：Python 不使用大括號 {}，而是強制使用縮排（慣例為 4 個空格）界定程式層級，縮排錯誤會引發 IndentationError。
  • 單行註解：以井字號 # 開頭，直譯器會忽略該行後方文字。
  • 多行註解 / 文件字串：使用三個單引號 ''' 或三個雙引號 """ 包夾。
變數命名規則（Identifier Rules）
  • 只能包含英文字母、數字、底線 _（也支援 Unicode 中文命名，但實務建議英文）。
  • 開頭不可為數字（例如 1score 為非法名稱）。
  • 大小寫有別（Score 與 score 為不同變數）。
  • 不可使用 Python 保留字（Keywords），如 if、for、class、True、None。

1.2 基本資料型別（Data Types）與 type()

int（整數）

正負整數與 0，支援任意精度大數，如 100、-25。

float（浮點數）

帶有小數點的數值或科學記號，如 3.14、2.5e3。

str（字串）

以單引號 ' ' 或雙引號 " " 包夾的字元序列。

bool（布林值）

只有 True（1）與 False（0），首字必須大寫。

1.3 運算子總覽與優先順序

運算類別 運算符號 重點說明與考題陷阱
算術運算子 +  -  *  /  //  %  ** / 永遠回傳浮點數（4/2 → 2.0）；// 取整數商；% 取餘數；** 為次方（右結合，2**3**2 = 512）。
複合指派 +=  -=  *=  /=  //=  %=  **= x += 3 等同 x = x + 3；注意 x =+ 3 是將正 3 指定給 x。
關係運算子 ==  !=  >  <  >=  <= 判斷相等必須用兩個等號 ==，一個等號 = 是指派運算。支援串接比較如 1 < x < 10。
邏輯運算子 not  >  and  >  or 優先順序為 not 最高，其次 and，最後 or。具有短路求值（Short-circuit）特性。
位元與成員 &  |  ^  <<  >>  in  is x << 2 左移 2 位元相當於乘以 4；is 比較記憶體位址是否為同一物件，== 比較值是否相等。

CHAPTER 03

流程控制：選擇結構（if / elif / else）

依據條件真假決定程式執行分支，包含單向、雙向、多向選擇與巢狀判斷。

3.1 多向選擇與三元條件運算式

Python 使用 elif（else if 的縮寫）串接多個條件，由上而下依序判斷，只要第一個條件成立並執行完畢，就會跳出整個 if-elif-else 結構。 

score = 82
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "C"

# 單行三元運算式：值1 if 條件 else 值2
status = "及格" if score >= 60 else "不及格"

3.2 認證考題高頻陷阱：真值測試（Truthiness）

在 Python 條件判斷中，以下值會被視為 False（Falsy），其餘皆視為 True：

  • 布林值 False 與空值 None
  • 數值零：0、0.0、0j
  • 空容器：""（空字串）、[]（空串列）、()（空元組）、{}（空字典）

⚠️ 注意：字串 "False" 或 "0" 因為長度不為 0，轉布林值時皆為 True！

CHAPTER 04

迴圈結構：for 與 while

掌握計數迴圈 range() 參數變化、條件迴圈 while，以及 break 與 continue 的控制流程。

4.1 range(start, stop, step) 三種用法

  • • range(5) → 0, 1, 2, 3, 4（共 5 個，不含 5）
  • • range(2, 6) → 2, 3, 4, 5（含頭不含尾）
  • • range(10, 0, -3) → 10, 7, 4, 1（負步長遞減）

⚠️ 若起始值小於終止值但步長為負數（如 range(2, 5, -2)），序列為空，迴圈執行 0 次。

4.2 break 與 continue 差異

  • • break：立即強制終止整個迴圈，跳至迴圈後方繼續執行（若巢狀迴圈則只跳出最內層迴圈）。
  • • continue：略過本次迴圈剩餘敘述，直接回到迴圈開頭進行下一輪判斷。
  • • else 子句：當迴圈正常執行完畢（非由 break 中斷）時會執行。

串列（List）與元組（Tuple）

想像你有一整排「有編號的置物櫃」，一次幫你把很多資料整齊收好！這一章我們放慢腳步，用最簡單的生活例子、一步一步帶你學會怎麼存資料、找資料、改資料與排順序。

5.1 什麼是串列（List）？怎麼建立與拿資料？

💡 老師白話說：為什麼需要「串列」？

以前存 5 個同學的成績，你可能要取 5 個變數：s1=85, s2=79, s3=93, s4=60, s5=100。如果全班有 40 個人怎麼辦？
串列（List）就是用一對中括號 [ ]，把好幾個資料用逗號 , 隔開，全部裝進同一個變數裡面！就像一列有編號的火車車廂。

🚃 想像一列火車：score = [85, 79, 93, 60, 100] ★ 超重要：電腦數數永遠從 0 開始！
第 1 節車廂
85
score[0]
倒數 score[-5]
第 2 節車廂
79
score[1]
倒數 score[-4]
第 3 節車廂
93
score[2]
倒數 score[-3]
第 4 節車廂
60
score[3]
倒數 score[-2]
最後一節
100
score[4]
倒數 score[-1]

👉 記憶口訣：從左邊數（正數）從 0 開始；從右邊倒數（負數）最後一個永遠是 -1！

📘 範例 1：建立各種串列與拿取資料

串列裡面可以放數字、文字，甚至混合放都可以！

# 建立飲料菜單串列
drinks = ["紅茶", "綠茶", "奶茶", "烏龍茶"]

print(drinks)       # 印出全部: ['紅茶', '綠茶', '奶茶', '烏龍茶']
print(drinks[0])    # 拿第1杯(編號0): 紅茶
print(drinks[2])    # 拿第3杯(編號2): 奶茶
print(drinks[-1])   # 拿最後1杯: 烏龍茶

# 混合不同資料型態（姓名、年齡、是否及格）
student = ["王小明", 16, True]
empty_box = []      # 空串列（裡面目前沒東西）
📘 範例 2：修改內容與二維串列（表格）

直接指定編號就能改掉裡面的值；串列裡面還可以再包串列。

drinks = ["紅茶", "綠茶", "奶茶"]
drinks[1] = "珍珠奶茶"   # 把編號1的綠茶改掉
print(drinks)          # ['紅茶', '珍珠奶茶', '奶茶']

# 二維串列：像是兩組帳號密碼表
users = [["joe", "1234"], ["mary", "abcd"]]
print(users[0])        # 第1組: ['joe', '1234']
print(users[1][1])     # 第2組的第2個資料: abcd
📘 範例 3：切片（Slicing）—— 一次切一段出來！

切片語法是 串列[開始編號 : 結束編號 : 間隔幾步]。
⚠️ 超級陷阱口訣：「有頭無尾」—— 結束編號不包含那一個！（例如 [0:2] 只會拿編號 0 和 1，不會拿 2）。 

books = ["書0", "書1", "書2", "書3", "書4", "書5"]

print(books[0:2])    # 拿編號 0 到 1 (不含2)  → ['書0', '書1']
print(books[:3])     # 省略開頭=從0開始到2   → ['書0', '書1', '書2']
print(books[3:])     # 省略結尾=從3拿到最後  → ['書3', '書4', '書5']
print(books[1::2])   # 從編號1(第2本)開始，每次跳2步(間隔1本) → ['書1', '書3', '書5']
🚨
新手最常犯錯誤（IndexError 超出範圍）：如果串列只有 3 個東西，編號只有 0, 1, 2。如果你寫 drinks[3]，電腦會生氣顯示 IndexError: list index out of range（找不到第 4 節車廂）。

5.2 用 for 迴圈把串列東西一個一個拿出來

當串列裡面有 100 個資料時，不可能手寫 100 行 print()。這時候搭配第四章學過的 for 迴圈，就能自動從頭到尾點名一遍！我們有兩種寫法：

📘 寫法一（最簡單）：直接拿東西

每次迴圈自動把串列裡的下一個元素放進變數 item。

fruits = ["香蕉", "蘋果", "橘子"]

for item in fruits:
    print("我喜歡吃", item)

# 執行結果：
# 我喜歡吃 香蕉
# 我喜歡吃 蘋果
# 我喜歡吃 橘子
📘 寫法二（搭配編號）：用 len() 算長度

len(串列) 可以算出共有幾個東西。有編號就能同時對照兩個串列！

names = ["小明", "小華", "小美"]
scores = [85, 92, 78]

# len(names) 是 3，range(3) 會產生 0, 1, 2
for i in range(len(names)):
    print(names[i], "考了", scores[i], "分")
📘 範例 4（實戰應用）：計算全班總分與平均分數
scores = [80, 90, 70, 100]
total = 0                 # 準備一個存錢筒，一開始是 0

for s in scores:
    total = total + s     # 把每個分數慢慢加進 total 裡面

avg = total / len(scores) # 總分除以人數 (340 / 4 = 85.0)
print("總分:", total, "平均:", avg)

5.3 在串列裡找東西（in / index / count）

想知道某個東西「在不在裡面？」、「排在第幾個位置？」、「總共出現幾次？」，只要記住這三個超好用的工具：

1. in 問在不在？

只會回答 True（在裡面）或 False（不在裡面），最安全不會報錯！

bag = ["鑰匙", "錢包", "手機"]
print("手機" in bag)   # True
print("雨傘" in bag)   # False
2. .index() 找編號

告訴你這個東西第一次出現的編號。⚠️ 如果找不到會當機報錯！

bag = ["鑰匙", "錢包", "手機"]
pos = bag.index("錢包")
print(pos)  # 輸出: 1 (第2個)
3. .count() 算次數

幫你數一數這個東西總共出現幾次。找不到會乖乖回答 0。

votes = ["A", "B", "A", "A"]
print(votes.count("A")) # 3
print(votes.count("C")) # 0

5.4 串列的新增（排隊）與刪除（離開）

➕ 新增資料 append() 與 insert()

  • 串列.append(新東西)：乖乖排在最後面（最常用！）。
  • 串列.insert(編號, 新東西)：插隊到指定的編號位置，原本在後面的人全部往後退一格。
line = ["小王", "小李"]

line.append("小張")      # 小張排最後 → ['小王', '小李', '小張']
line.insert(1, "VIP")    # VIP插隊到編號1 → ['小王', 'VIP', '小李', '小張']
print(line)

➖ 刪除資料 remove()、pop() 與 del

  • 串列.remove(資料內容)：指名道姓把某個資料踢掉（只刪第一個找到的）。
  • 串列.pop()：把最後一個資料抓出來並刪除（括號寫編號也可抓指定位置）。
  • del 串列[:] 或 串列.clear()：把整排清空變成 []。
lst = ["apple", "banana", "cherry"]

lst.remove("apple")  # 指名刪 apple → ['banana', 'cherry']
last = lst.pop()     # 抓出最後一個 'cherry'，lst 剩 ['banana']
del lst[:]           # 全部清空 → []

5.5 串列排隊大小（sort / reverse / sorted）

想把成績從低排到高，或從高排到低？只要分清楚「直接改原本串列」和「複製一份新的再排」兩種方法就不會搞混！

方法 A：直接修改原本串列（.sort() / .reverse()）

.sort() 會把原本的串列直接重新排好（預設由小到大）。如果想要由大到小，只要排完再加一行 .reverse() 把整排倒過來就好！ 

nums = [40, 10, 50, 20]
nums.sort()      # 變成 [10, 20, 40, 50] (小到大)
nums.reverse()   # 倒過來 [50, 40, 20, 10] (大到小)
print(nums)

方法 B：保留原本串列不動（sorted()）

如果你不想破壞原本的順序，要用 sorted(串列)，它會生出一個全新的排好序串列給你。 

a = [3, 1, 2]
b = sorted(a)                # b 是 [1, 2, 3]
c = sorted(a, reverse=True)  # c 是 [3, 2, 1]
print(a)                     # a 還是原本的 [3, 1, 2]！

5.6 第五章隨身小抄：串列常用指令一覽表

假設 L = [1, 2, 3, 4, 5, 6]
指令寫法 白話功能說明 實際結果範例
len(L) 算一算串列裡面共有幾個東西 len(L) → 6
min(L) / max(L) 找出裡面最小 / 最大的數字 min(L) → 1 / max(L) → 6
L[1:4:2] 從編號1切到3(不含4)，每次跳2步 [2, 4]
L.index(3) 找數字 3 排在第幾號位置 2（第3個位置）
L.count(3) 數一數數字 3 總共出現幾次 1
L.append(8) 把 8 加到最後面 [1, 2, 3, 4, 5, 6, 8]
L.insert(3, 8) 把 8 插隊放到編號 3 的位置 [1, 2, 3, 8, 4, 5, 6]
L.pop() 把最後一個東西拿出來並刪掉 拿出 6，L 剩 [1, 2, 3, 4, 5]
L.remove(3) 把第一個看到的 3 刪掉 [1, 2, 4, 5, 6]
del L[:] / L.clear() 清空全部元素 []
L.sort() / L.reverse() 由小到大排好 / 整排前後反轉 [6, 5, 4, 3, 2, 1]

5.7 元組（Tuple）—— 用保鮮膜封起來的串列！

🍱 老師白話說：什麼是元組（Tuple）？

元組（Tuple）也叫「序對」，寫法跟串列幾乎一模一樣，只是把中括號 [ ] 換成小括號 ( )。
它就像「用保鮮膜緊緊封起來的便當盒」：你可以看裡面有什麼菜（用 t[0] 讀取），但絕對不能打開來偷換菜或加菜（不能修改、不能新增、不能刪除）！適合用來保護生日、身分證字號等不該被改掉的資料。

串列 List [ ] 可以修改 (Mutable)
  • • 用中括號 [10, 20, 30]
  • • 可以寫 lst[0] = 99 改內容
  • • 可以用 append()、remove()
元組 Tuple ( ) 不能修改 (Immutable)
  • • 用小括號 (10, 20, 30)
  • • 不可以寫 t[0] = 99（會當機報錯！）
  • • 沒有 append() 也沒有 remove()

📘 範例 5：如果真的想改元組怎麼辦？先用 list() 拆開保鮮膜！

# 建立一個元組（用小括號）
t1 = (10, 20, 30)
print(t1[0])          # 可以偷看第1個資料 → 10
# t1[0] = 99          # ❌ 這行會報錯！因為元組不能直接修改

# 破解法：先用 list() 轉成串列 → 修改好 → 再用 tuple() 封回去！
temp_list = list(t1)  # 變成串列 [10, 20, 30]
